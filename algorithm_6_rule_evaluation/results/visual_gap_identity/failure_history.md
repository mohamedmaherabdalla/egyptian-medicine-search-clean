# Visual-gap exact-identity benchmark: failure history

## Generation protocol

The generator reads the current 25,066-row catalog and derives 17,476 exact
base-family keys from `b` (falling back to `n`). It independently reconstructs
catalog family-head surfaces from first-token and manufacturer overlap, then
enumerates positional prefix, suffix, internal, both-edge, multi-fragment, and
shorthand indexes. It never imports Algorithm 5/6, calls the API, or reads a
prior result.

Every case records the exact source base-family key and the complete set of
exact base-family keys satisfying its literal oracle. Explicit gaps require at
least one hidden target character at each internal or edge marker. OCR-plus-gap
rows use the union of raw exact matches and matches after the one declared
directional observed-to-catalog rewrite; rewrites never chain. The evaluator
reads only `matched_family_key` for visual result identity and never treats a
`variant_group` as a label.

The split is deterministic and family-stable: SHA-256 of the seed and exact
family key assigns one fifth to holdout. A multi-family row is eligible only
when its source, relevant, and forbidden exact families all share the split.

  - `VGI-53E23F4CD7235073`, query `MOO*VMASSAGE`
- Observed behavior: both queries correctly entered explicit visual-gap mode
  with internal fragments and returned no candidates.
- Root cause: benchmark label defect. The current parser regex intentionally
  defines a single star as a marker (`\*+`). The generator had incorrectly
  put `*` in the single non-marker punctuation stratum. A single question mark
  is also a valid marker (`\?+`) and was audited at the same time.

No runtime algorithm change was justified or made. The initial dataset,
per-case outcomes, summary, and failures CSV remain versioned in the run
directory. The content-addressed raw API log remains in the local evaluation
archive and can be regenerated by the evaluator.

## Oracle correction and final rerun — `20260822T173010Z`

The generator was corrected narrowly:

- `*` and `?` are positive marker-grammar glyphs;
- negative single-punctuation guards use only `-`, `.`, `/`, `:`, `+`, and `_`;
- the selected marker stratum is checked to cover every current glyph form:
  `..`, `.....`, `…`, `*`, `***`, `?`, `???`, `__`, and mixed `...__`.

The corrected dataset first passed in preserved run `20260822T172826Z`. Run
`20260822T173010Z` repeats the same 424 responses and metrics after a

clinical precision or blind generalization.
